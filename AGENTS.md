# Tatame — notes for agents

- **Git commits** — Write all commit messages in English (subject and body).
- Architecture spec: `docs/superpowers/specs/2026-03-19-tatame-architecture-design.md`
- Monorepo: **pnpm** workspaces + **Turborepo**
- Database: **PostgreSQL** + **Drizzle** in `packages/db`
- API: `apps/api` (modular Express); **Clerk** — `clerkMiddleware` when `CLERK_SECRET_KEY` is set; mobile calls `POST /v1/users/me/sync` after login to upsert user (optional body `role` for first-time role); `GET /v1/users/me`; `authorize(...roles)` sets `req.appAuth` from `user_roles`; after it, `attachActiveAcademyContext` fills `activeAcademyId` + `academyRole` from the active `academy_memberships` row (if any); `requireActiveAcademy` → 403 when missing
- **Academy / membership** — `GET/POST/PATCH /v1/academies`, `GET ?q=` search; `POST /v1/memberships/requests`, `GET /v1/memberships/pending?academyId=`, `PATCH .../approve|reject|block|unblock`, `POST /v1/memberships/leave`. Pending rows use `is_active: false`; exactly one `is_active` membership per user.
- **Classes** — `GET/POST /v1/classes`, `GET/PATCH/DELETE /v1/classes/:classId` scoped to active academy. Manager: full CRUD (`assertManagerOwnsAcademy`); instructor: create/update/delete only own classes; students: read schedule. `DELETE` sets `is_active: false`. Query: `dayOfWeek`, `includeInactive` (managers only).
- **Subscriptions** — `GET /v1/subscriptions/plans` (`?includeInactive=true` managers only), `POST /v1/subscriptions/plans` (manager, owner), `GET/PATCH /v1/subscriptions/plans/:planId`; `GET /v1/subscriptions/me` (current sub for active academy + `expiredByDate` / `effectiveStatus`); `POST /v1/subscriptions/me/plan` (student + `academyRole` student). Expiry: `expires_at < today` treated as expired; DB `status` opportunistically set to `expired` on read.
- **Payments (manual MVP)** — `POST /v1/payments` (manager, owner of active academy): `subscriptionId`, `amountCents`, `referenceMonth` (YYYY-MM-01), optional `notes`, optional `paidAt` (ISO datetime); `method=manual`, `confirmed_by` set. `GET /v1/payments` (manager) lists academy payments, optional `?subscriptionId=`; `GET /v1/payments/me` (student) lists own payments in active academy.
- **Graduations (belt)** — `POST /v1/graduations/initial` (student + `academyRole` student): first belt/stripes after approval; `promoted_by` = own user id. `POST /v1/graduations` (manager owner of active academy or active instructor in that academy): body `studentUserId`, `belt`, `stripes`, optional `notes`; requires student already has current belt; validates progression (higher belt or more stripes on same belt) and stripe caps (`MAX_STRIPES_BY_BELT`). `GET /v1/graduations/me` (student): own history in active academy. `GET /v1/graduations?userId=` (manager/instructor): target must be active student in active academy.
- **Check-ins** — `POST /v1/checkins` (global role student + `academyRole` student + membership `status=active`): body `classId`, `date` (session calendar date YYYY-MM-DD, UTC with class times); window opens 12h before class start until class end (handles end after midnight); Redis lock `checkin:lock:{class_id}:{date}` (~5s TTL, one retry 500ms); inside lock: class `capacity` + plan `weekly_checkin_limit` (null = unlimited); unique `(user_id, class_id, date)`; `week_reference` = Monday of that week. After `expires_at`, check-in allowed until end of 3rd calendar day (`warnings.subscriptionGrace`); while not expired, missing payment for current month (`reference_month` = YYYY-MM-01) → `warnings.paymentOverdue`. No Redis / connection failure → 503; lock busy → 429.
- Redis (`node-redis` v4) for check-in locks only — `apps/api/src/lib/redis.ts`, `lock.ts`
- **CI / tests** — GitHub Actions `.github/workflows/ci.yml`: `pnpm install --frozen-lockfile`, `pnpm build`, then `pnpm test:unit` and `pnpm test:integration` (API integration uses **Testcontainers** → runner needs **Docker**, e.g. `ubuntu-latest`). Root: `pnpm test` = full suite; `pnpm test:unit` / `pnpm test:integration` via Turbo (`apps/api` Vitest projects). API: smoke HTTP, serviços com repos in-memory, e `*.integration.test.ts` (HTTP + Postgres real).
- Local stack: `docker compose up -d` (Postgres + Redis) — URLs in `.env.example`
- After schema changes: `pnpm db:generate`, then `pnpm db:migrate` with `DATABASE_URL` set
- **Mobile** — `apps/mobile`: Expo SDK 54 (managed), Expo Router, **NativeWind v4** (Tailwind for RN), **Poppins** font (single family), `lucide-react-native` icons, **Clerk Expo SDK** (custom flows). Custom modal-based select (no native select). Metro config: `watchFolders` + `nodeModulesPaths` for pnpm monorepo. Specs: `docs/superpowers/specs/2026-03-24-mobile-base-onboarding-design.md`, `docs/superpowers/specs/2026-03-24-auth-screens-clerk-design.md`
